# Android client scaffold

Open this folder in Android Studio and use JDK 17. This is currently a UI scaffold; it does not yet call the backend API. The configured 10.0.2.2 URL is for an Android emulator reaching a backend on the host computer. Before a release build, change ApiConfig.BASE_URL to the deployed HTTPS API URL and implement authenticated API calls.

Do not enter real credit report details into this prototype.
